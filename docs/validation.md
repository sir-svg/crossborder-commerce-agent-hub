# 验证记录

验证环境：Windows，Python 3.13，项目 `uv.lock` 固定的依赖。这里区分已经实际运行的检查与仅提供配置的部分。

## 已运行

- 58项 pytest 检查：库存、确认前不写入、重复确认、补货去重、供应商库存不足、数量边界、配送扣库存、跨会话重复配送阻止、会话记忆与隔离、资料来源、未知实体、多个助手共享订单上下文、输入校验、忙碌会话拒绝、A2A Card/Task/Artifact，以及网页登录、会话 Cookie、退出撤销、过期与伪造会话、跨站请求、输入转义和未授权请求拦截。
- 使用独立本地 HTTP 服务验证 A2A 委派供应商和物流，再由外部 Agent 调用 Streamable HTTP MCP 工具服务；不是只调用 Python 业务函数。
- 外部供应商不可用时保留本地商品结果，禁止生成补货单；模型不可用时回退规则并保留工具事实。
- SQLite 记忆适配器重新创建后仍能读取会话实体。
- 浏览器实际操作：提交库存任务、确认补货并看到库存变化、安排并确认配送、切换订单页面、新建会话。
- 桌面1440px和手机390px页面检查，未发现页面脚本错误或手机页面整体横向溢出。
- 界面改版后复查320、390、768、1024、1440px布局；目的市场筛选、线路高亮和快捷营销指令的市场切换均已实际操作验证。
- Ruff 检查、Python 格式检查、JavaScript 语法检查。
- `render.yaml` 已对照 Render 官方 JSON Schema 验证；只定义一个 Free Web Service，没有数据库和付费磁盘。
- 模拟线上密码模式的浏览器检查已通过，页面临时数据提示、登录后的商品查询、SSE、补货和配送均正常。
- 新网页登录流程在实际浏览器中检查了错误密码、显示/隐藏密码、登录成功、刷新保持登录、补货确认和退出；还验证了关闭 JavaScript 时可提交登录表单，以及320、390、768、1440px登录页面布局。
