# 验证记录

验证环境：Windows，Python 3.13，项目 `uv.lock` 固定的依赖。这里区分已经实际运行的检查与仅提供配置的部分。

## 已运行

- 25项 pytest 检查：库存、确认前不写入、重复确认、补货去重、供应商库存不足、数量边界、配送扣库存、跨会话重复配送阻止、会话记忆与隔离、资料来源、未知实体、多个助手共享订单上下文、输入校验、忙碌会话拒绝、A2A Card/Task/Artifact。
- 使用独立本地 HTTP 服务验证 A2A 委派供应商和物流，再由外部 Agent 调用 Streamable HTTP MCP 工具服务；不是只调用 Python 业务函数。
- 外部供应商不可用时保留本地商品结果，禁止生成补货单；模型不可用时回退规则并保留工具事实。
- SQLite 记忆适配器重新创建后仍能读取会话实体。
- 浏览器实际操作：提交库存任务、确认补货并看到库存变化、安排并确认配送、切换订单页面、新建会话。
- 桌面1440px和手机390px页面检查，未发现页面脚本错误或手机页面整体横向溢出。
- Ruff 检查、Python 格式检查、JavaScript 语法检查。

- 真实模型服务成功响应；已检查不可用时的回退行为，未配置商用密钥。
