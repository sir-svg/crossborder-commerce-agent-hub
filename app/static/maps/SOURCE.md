# World geographic data

The map uses the public-domain Natural Earth 1:110m admin-0 countries dataset.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

The original geometry is simplified at 1:110m; this derivative retains country
name/code and rounds coordinates to three decimal places. The file is hosted
with the application (no map service, tiles, or API key required). Generalized
boundaries are for visual demonstration, not a legal or navigation reference.
